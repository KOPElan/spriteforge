spriteforge

短视频 → AI 抠图 → Sprite Sheet（Unity 友好），本地运行，无需上传到第三方。

1. 导入视频

把视频拖到这里，或

支持 mp4 / mov / webm / avi / mkv，单个文件上限 200MB；典型输入 1–3 秒、720×720 及以下。

2. 参数

边缘去溢色

自定义颜色需为饱和色（比如某种绿色、蓝色），白/灰/黑色幕布没有颜色溢色可去，去溢色对它不起作用。幕布颜色要和角色主色错开，否则细小的同色元素也可能被洗掉。

首次运行需联网下载模型（BiRefNet-general 约 1GB），下载期间进度会停在 20–30% 一段时间，属于正常现象，之后可离线使用。

参数会自动记住上次提交的值（存在浏览器本地），下次打开页面直接沿用；换浏览器或设备时，第一次会先用最近一次历史任务的参数。

自动循环建议

按剪影差异算首尾跳变，跳变比接近 1 表示跳回首帧跟正常走一步差不多大；这只是建议，最终以循环预览的人眼为准，系统不知道哪段才是一个完整的走路动作。

导出

下载 sprite.png 下载 index.json 下载 ZIP（合图 + 索引 + 单帧）

Unity 使用：把 sprite.png 导入为 Sprite（Multiple），或按 index.json 里的 unity_x / unity_y（左下角原点）和 pivot（0.5, 0.5）用 Sprite.Create 逐帧创建。

历史记录

历史保存在 jobs/ 目录下，服务重启后仍可查看和删除；删除会连同该任务的原视频、单帧、合图一起删掉，导出过的结果请先另存。生成失败的任务不进历史：失败时原视频和已生成的部分文件会一起删掉，失败原因只在当时进度卡片里显示，重新生成请点失败后的“重新生成”（浏览器里还留着你选的视频）。没有 job.json 的旧任务文件夹不会显示（项目还在开发阶段，不做向前兼容）。
